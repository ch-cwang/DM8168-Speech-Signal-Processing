# 软件测试报告

## 1. 测试概述

对双核音频流控系统进行功能、压力与稳定性测试，验证零拷贝直通、抗撕裂与优雅退出。

## 2. 测试环境

- 硬件：DM8168 开发板、3.5 mm 音频线、PC（在线音源与 Audacity）。
- 软件：已编译的 `app` 与 `server.xe674`、ALSA snoop 旁路抓包。
- 音频参数：48 kHz / 16 位 / 双声道。

## 3. 测试结果

| 用例 | 描述 | 结果 |
|------|------|------|
| 用例 1 | 基础直通与音质 | 通过 |
| 用例 2 | CPU 满载抗撕裂 | 通过 |
| 用例 3 | 频繁启停防死锁 | 通过 |
| 用例 4 | 冷启动预充水防爆音 | 通过 |

### 3.1 用例说明

- 用例 1：验证 ALSA 参数配置与 DSP 直通拷贝，波形平滑、无丢帧断点。
- 用例 2：验证 CPU 满载时 offset 拼装与 400 ms 缓冲深度，波形无错位撕裂。
- 用例 3：验证频繁启停下 `snd_pcm_drop`、`sem_post` 与四次握手，无死锁、无资源泄漏。
- 用例 4：验证 `start_threshold` 预充水，启动首秒无爆音，波形平滑过渡。

## 4. 结论

系统在零互斥锁、零逻辑拷贝的架构下通过全部测试，满足实时性与容错性要求，可进入算法研发阶段。
